# Images Directory

This directory contains static images for the Kabini.ai blog website.

## Recommended Images to Add:

### Logo and Branding
- `logo.png` - Main Kabini.ai logo
- `logo-white.png` - White version of logo for dark backgrounds
- `favicon.ico` - Website favicon (16x16, 32x32, 48x48 pixels)

### Contact Page
- `contact-hero.jpg` - Hero image for contact page
- `office.jpg` - Office or team photo
- `team-photo.jpg` - Team photo for about section

### Blog
- `blog-placeholder.jpg` - Default image for blog posts without cover images
- `author-avatars/` - Directory for author profile pictures

### General
- `og-image.jpg` - Open Graph image for social media sharing (1200x630px)
- `hero-bg.jpg` - Background image for hero sections

## Image Guidelines:
- Use WebP format when possible for better performance
- Optimize images for web (compress without losing quality)
- Use descriptive filenames
- Include alt text in your components
- Recommended sizes:
  - Hero images: 1920x1080px
  - Blog covers: 1200x630px
  - Thumbnails: 400x300px
  - Profile pictures: 200x200px
